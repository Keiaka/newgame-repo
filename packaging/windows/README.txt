AZEROTH SURVIVORS - WINDOWS x64

1. Extract the entire ZIP into a writable folder (not Program Files).
2. Double-click Play.cmd.
3. On first launch, supply your WoW 1.12.1 Data folder beside Play.cmd,
   or accept the download from the upstream project's archive.org source.
   Allow ~12 GB free space during setup and a ~5.5 GB download.
4. Later launches reuse the downloaded data.

Requires Windows 10/11 x64, an updated graphics driver and a GPU supported by Bevy.
No Godot, Rust or Python installation is required.
If Windows reports missing VCRUNTIME/MSVCP DLLs, install Microsoft's x64
Visual C++ Redistributable: https://aka.ms/vs/17/release/vc_redist.x64.exe

This is the imported open-source reimplementation, not the original game's
complete current feature set. The ZIP contains no Blizzard game data.
